# Mobile Practice App website

A simple static site for GitHub Pages.

## Replace the app link
Open `index.html` and replace `#APP-LINK` in the **Open the App** button with the real app URL.

## GitHub Pages
1. Create a GitHub repository (for example `mobile-practice-app`).
2. Upload the contents of this folder to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/mobile-practice-app/`.
